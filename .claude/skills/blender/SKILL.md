# Blender

One skill, many modules. This file only routes; the real guidance lives in `modules/<name>/guide.md` and is loaded on demand, so read only what the task needs.

## How to use this skill

1. **Multi-step or ambiguous job** (new asset, full pipeline, reference-image match, anything spanning disciplines): read `modules/blender-director/guide.md` first. It holds the production workflow (analyze, plan, brief, delegate, execute, validate, deliver) and a routing table from request type to module.
2. **Narrow, clear job** (e.g. "unwrap this", "set up three-point light"): skip the director and read just the matching module from the index below.
3. **Style, mood, world, genre** modules are overlays. Pair one or two with a technical module (e.g. `lowpoly-style` + `hard-surface` + `unity-export`) rather than loading many. If styles conflict, ask the user which wins.
4. Open a module's `references/` files only when its `guide.md` points to them or the task needs that detail.

Each module is `modules/<name>/guide.md` plus optional `modules/<name>/references/*.md`. Module guides mention other modules by name; resolve any name through the index below. Paths like `shared/asset-pipeline.md` are relative to this folder.

## Ground rules

- **Execute through MCP when Blender MCP is available** instead of describing UI clicks; fall back to bpy scripts, then manual steps only if neither exists. Details: `shared/mcp-integration.md`, tool catalog: `shared/mcp-tools.md`.
- **Plan before building**: asset purpose, target platform, polycount and texture budgets, export format. Budgets: `shared/polycount-budgets.md`; pipeline: `shared/asset-pipeline.md`.
- **Validate before delivering**: `shared/validation-checklist.md`, naming in `shared/naming-conventions.md`.
- **Reference image supplied**: follow `shared/reference-image-match.md`, write the analysis from `shared/reference-analysis-template.md` first, match camera before micro-detail, then check with `shared/visual-match-checklist.md`.
- Prefer non-destructive workflows (modifiers, collections, linked data) so the user can iterate.
- If a module is missing something the task needs, say so instead of improvising silently.
